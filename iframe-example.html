Embedded Form Example

This is an example of embedding the form in an iframe.

The form below is loaded from sample-form.html using an iframe. This demonstrates how the form can be embedded in any website.

Note: Update the form's fetch URL in sample-form.html to point to your deployed Azure Function endpoint before using in production.

For Production Use:

  1. Deploy your Azure Function to Azure
  2. Update the fetch URL in sample-form.html to your Azure Function URL
  3. Host sample-form.html on your web server
  4. Embed it in your website using an iframe like this:
<iframe src="https://your-domain.com/sample-form.html" width="600" height="500"></iframe>
